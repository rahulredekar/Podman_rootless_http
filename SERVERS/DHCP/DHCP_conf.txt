# 🔵 3. DHCP CONFIGURATION

```bash id="dh2"

```

```conf id="dh3"
default-lease-time 600;
max-lease-time 7200;
authoritative;

subnet 192.168.83.0 netmask 255.255.255.0 {

    range 192.168.83.100 192.168.83.200;

    option routers 192.168.83.1;

    option domain-name "vaibhav.com";

    option domain-name-servers 192.168.83.6, 192.168.83.7;

    option broadcast-address 192.168.83.255;
}
```
