# 🔵 STEP 1 — iSCSI SERVER (TARGET)

## 📍 RUN ON: iscsi-server (192.168.83.30)

---

## 1. Install iSCSI target software

```bash
sudo dnf install targetcli -y
```

**Installs LIO iSCSI target management tool**

---

## 2. Enable iSCSI target service

```bash
sudo systemctl enable --now target
```

**Starts iSCSI target daemon**

---

## 3. Create storage backend (LUN)

```bash
sudo mkdir -p /iscsi
sudo fallocate -l 10G /iscsi/disk1.img
```

**Creates a 10GB block storage file**

---

## 4. Configure iSCSI target

```bash
sudo targetcli
```

---

Inside `targetcli`:

### Create backstore

```bash
backstores/fileio create disk1 /iscsi/disk1.img 10G
```

**Defines storage disk**

---

### Create iSCSI target

```bash
iscsi/ create iqn.2026.com.vaibhav:storage1
```

**Creates iSCSI target name**

---

### Map LUN

```bash
cd iscsi/iqn.2026.com.vaibhav:storage1/tpg1/luns
create /backstores/fileio/disk1
```

**Attaches disk to target**

---

### Allow client access (ACL)

```bash
cd ../acls
create iqn.2026.com.vaibhav:client1
```

**Only this client can connect**

---

### Open portal

```bash
cd ../portals
create 0.0.0.0 3260
```

**Listens on all interfaces**

---

### Save config

```bash
exit
sudo targetctl saveconfig
```

---

## 5. Firewall rule (SERVER)

```bash
sudo firewall-cmd --permanent --add-port=3260/tcp
sudo firewall-cmd --reload
```

**Opens iSCSI port**

---

# 🔵 STEP 2 — iSCSI CLIENT (INITIATOR)

## 📍 RUN ON: iscsi-client (RHEL 9/10)

---

## 1. Install initiator tools

```bash
sudo dnf install iscsi-initiator-utils -y
```

**Installs iSCSI client tools**

---

## 2. Set initiator IQN

```bash
sudo vim /etc/iscsi/initiatorname.iscsi
```

```conf
InitiatorName=iqn.2026.com.vaibhav:client1
```

---

## 3. Enable service

```bash
sudo systemctl enable --now iscsid
```

**Starts iSCSI daemon**

---

## 4. Discover storage

```bash
sudo iscsiadm -m discovery -t sendtargets -p 192.168.83.30
```

**Finds available iSCSI targets**

---

## 5. Login to target

```bash
sudo iscsiadm -m node -T iqn.2026.com.vaibhav:storage1 -p 192.168.83.30 --login
```

**Connects to remote disk**

---

## 6. Verify disk

```bash
lsblk
```

**New disk appears (e.g. /dev/sdb)**

---

## 7. Enable auto-login

```bash
sudo iscsiadm -m node -T iqn.2026.com.vaibhav:storage1 -p 192.168.83.30 \
--op update -n node.startup -v automatic
```

---

# 💾 STEP 3 — FORMAT & MOUNT (CLIENT)

---

## 1. Format disk

```bash
sudo mkfs.ext4 /dev/sdb
```

---

## 2. Create mount point

```bash
sudo mkdir -p /iscsi-data
```

---

## 3. Mount disk

```bash
sudo mount /dev/sdb /iscsi-data
```

---

## 4. Make persistent mount

```bash
sudo blkid /dev/sdb
```

Add to fstab:

```bash
sudo vim /etc/fstab
```

```conf
UUID=xxxx-xxxx  /iscsi-data  ext4  _netdev  0  0
```

**_netdev ensures network waits before mount**
