# 🔐 STEP 1 — LDAP SERVER SETUP (ldap1)

## 📍 RUN ON: ldap1 (192.168.83.20)

---

## 1. Install LDAP server

```bash id="l1"
sudo dnf install openldap-servers openldap-clients -y
```

---

## 2. Enable service

```bash id="l2"
sudo systemctl enable --now slapd
```

---

## 3. Create admin password

```bash id="l3"
slappasswd
```

👉 Save hashed password

---

## 4. Base domain setup (secure bind method)

```bash id="l4"
cat <<EOF > base.ldif
dn: dc=vaibhav,dc=com
objectClass: dcObject
objectClass: organization
o: Vaibhav Secure LDAP
dc: vaibhav
EOF
```

```bash id="l5"
ldapadd -x -D "cn=admin,dc=vaibhav,dc=com" -W -f base.ldif
```

---

## 5. Directory structure

```bash id="l6"
cat <<EOF > structure.ldif
dn: ou=People,dc=vaibhav,dc=com
objectClass: organizationalUnit
ou: People

dn: ou=Groups,dc=vaibhav,dc=com
objectClass: organizationalUnit
ou: Groups
EOF
```

```bash id="l7"
ldapadd -x -D "cn=admin,dc=vaibhav,dc=com" -W -f structure.ldif
```

---

# 🔐 STEP 2 — TLS SECURITY (MANDATORY)

## 📍 RUN ON: ldap1

---

## 1. Create certificates

```bash id="t1"
sudo mkdir -p /etc/openldap/certs
cd /etc/openldap/certs
```

```bash id="t2"
sudo openssl req -new -x509 -nodes -days 3650 \
-out ldap.crt -keyout ldap.key
```

---

## 2. Secure permissions

```bash id="t3"
sudo chown ldap:ldap ldap.key
sudo chmod 600 ldap.key
```

---

## 3. Enable TLS in LDAP

```bash id="t4"
cat <<EOF > tls.ldif
dn: cn=config
changetype: modify
add: olcTLSCertificateFile
olcTLSCertificateFile: /etc/openldap/certs/ldap.crt
-
add: olcTLSCertificateKeyFile
olcTLSCertificateKeyFile: /etc/openldap/certs/ldap.key
EOF
```

```bash id="t5"
ldapmodify -Y EXTERNAL -H ldapi:/// -f tls.ldif
```

---

## 4. FORCE LDAP TO BE SECURE ONLY (IMPORTANT)

```bash id="t6"
cat <<EOF > security.ldif
dn: cn=config
changetype: modify
replace: olcSecurity
olcSecurity: ssf=128
EOF
```

```bash id="t7"
ldapmodify -Y EXTERNAL -H ldapi:/// -f security.ldif
```

# 🔥 STEP 3 — FIREWALL (SECURE ONLY)

## 📍 RUN ON: ldap1

```bash id="f1"
sudo firewall-cmd --permanent --add-service=ldap
sudo firewall-cmd --permanent --add-service=ldaps
sudo firewall-cmd --reload
```

# 🟢 STEP 4 — CLIENT CONFIG (RHEL 9/10)

## 📍 RUN ON ALL CLIENTS

---

## 1. Install client tools

```bash id="c1"
sudo dnf install sssd sssd-ldap openldap-clients authselect oddjob oddjob-mkhomedir -y
```

---

## 2. Enable SSSD mode

```bash id="c2"
sudo authselect select sssd with-mkhomedir --force
```

---

## 3. Secure SSSD configuration

```bash id="c3"
sudo vim /etc/sssd/sssd.conf
```

```ini id="c4"
[sssd]
services = nss, pam
config_file_version = 2
domains = default

[domain/default]

id_provider = ldap
auth_provider = ldap

ldap_uri = ldap://192.168.83.20
ldap_search_base = dc=vaibhav,dc=com

ldap_tls_reqcert = demand
cache_credentials = true
enumerate = false
```

---

## 4. Secure permissions

```bash id="c5"
sudo chmod 600 /etc/sssd/sssd.conf
sudo systemctl enable --now sssd
```

---

## 5. Enable home directories

```bash id="c6"
sudo systemctl enable --now oddjobd
```
