# 🟢 2. SERVER SIDE SETUP (RHEL 9/10 + Ubuntu 24)

---

## 📌 INSTALL SAMBA

### RHEL

```bash id="srv1"
sudo dnf install -y samba samba-client samba-common acl policycoreutils-python-utils
```

### Ubuntu

```bash id="srv2"
sudo apt update
sudo apt install -y samba acl
```

---

## 📌 ENABLE SERVICES

```bash id="srv3"
sudo systemctl enable --now smb nmb
```

---

## 📌 CREATE SHARE DIRECTORY

```bash id="srv4"
sudo mkdir -p /srv/samba/share
sudo chmod 2770 /srv/samba/share
sudo chown -R root:users /srv/samba/share
```

---

# 🟢 3. ACL CONFIGURATION (SERVER SIDE)

```bash id="acl1"
sudo setfacl -m g:users:rwx /srv/samba/share
sudo setfacl -m d:g:users:rwx /srv/samba/share
```

---

Verify:

```bash id="acl2"
getfacl /srv/samba/share
```

# 🟢 4. SELINUX (RHEL ONLY – MANDATORY)


```bash id="se2"
sudo restorecon -Rv /srv/samba
```

# 🟢 5. SAMBA CONFIGURATION (SERVER SIDE)

Edit:

```bash id="cfg1"
sudo nano /etc/samba/smb.conf
```

---

## 🔐 FINAL HARDENED CONFIG

```ini id="cfg2"
[global]
   workgroup = WORKGROUP
   security = user
   map to guest = never

   server min protocol = SMB2
   server max protocol = SMB3

   smb encrypt = required
   ntlm auth = no

[share]
   path = /srv/samba/share
   browseable = yes
   writable = yes
   valid users = @users
   guest ok = no
```

---

## APPLY CONFIG

```bash id="cfg3"
testparm
sudo systemctl restart smb nmb
```

---

```bash id="cli1"

```

---

## 📌 CREATE MOUNT POINT

```bash id="cli2"
sudo mkdir -p /mnt/smb
```

---

## 📌 CREDENTIAL FILE (SECURE)

```bash id="cli3"
sudo nano /etc/samba/cred
```

```text id="cli4"
username=smbuser
password=StrongPassword
```

```bash id="cli5"
sudo chmod 600 /etc/samba/cred
```

---

## 📌 MANUAL MOUNT

```bash id="cli6"
sudo mount -t cifs //server_ip/share /mnt/smb \
-o credentials=/etc/samba/cred,vers=3.1.1,_netdev
```
