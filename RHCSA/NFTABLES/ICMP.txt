# nftables ICMP / ICMPv6 Guide (Echo Request & Echo Reply)

For:

* Red Hat Enterprise Linux
* Ubuntu
* nftables

This guide covers:

* ICMP basics
* Echo request/reply
* IPv4 + IPv6
* Secure vs unsecure rules
* Allow/block ping
* Rate limiting
* Selected IP/subnet ping rules
* Logging
* Forward chain ICMP
* Production-safe ICMP rules
* Delete commands

---

# 1. What is ICMP?

ICMP = Internet Control Message Protocol

Used for:

* ping
* traceroute
* network diagnostics
* MTU discovery

---

# 2. ICMP Echo Types

| ICMP Type    | Meaning       |
| ------------ | ------------- |
| echo-request | Ping request  |
| echo-reply   | Ping response |

---

# 3. Basic Ping Flow

```text
Client ---> echo-request ---> Server
Client <--- echo-reply <--- Server
```

---

# 4. Allow ALL ICMP (IPv4)

## ✅ Secure-ish basic rule

```bash
sudo nft add rule inet filter input ip protocol icmp accept
```

Description:

* Allows all IPv4 ICMP packets

---

## Delete Rule

```bash
sudo nft delete rule inet filter input handle <ID>
```

---

# 5. ❌ Unsecure Alternative

```bash
sudo nft add rule inet filter input accept
```

Problem:

* Allows EVERYTHING, not only ICMP

---

# Difference

| Secure     | Unsecure               |
| ---------- | ---------------------- |
| ICMP only  | Entire firewall bypass |
| Controlled | Fully open             |

---

# 6. Allow ONLY Echo Request (Ping)

## ✅ Secure

```bash
sudo nft add rule inet filter input icmp type echo-request accept
```

Description:

* Allows incoming ping requests only

---

## Delete Rule

```bash
sudo nft delete rule inet filter input handle <ID>
```

---

# 7. Allow ONLY Echo Reply

## ✅ Secure

```bash
sudo nft add rule inet filter input icmp type echo-reply accept
```

Description:

* Allows ping replies only

Useful:

* System can ping out
* External users cannot ping server

---

## Delete Rule

```bash
sudo nft delete rule inet filter input handle <ID>
```

---

# 8. Block Ping Requests

## ✅ Secure

```bash
sudo nft add rule inet filter input icmp type echo-request drop
```

Description:

* Blocks incoming ping

---

## Delete Rule

```bash
sudo nft delete rule inet filter input handle <ID>
```

---

# 9. ❌ Unsecure ICMP Blocking

```bash
sudo nft add rule inet filter input ip protocol icmp drop
```

Problem:

* Breaks PMTU discovery
* Can break networking/troubleshooting

---

# Difference

| Secure           | Unsecure        |
| ---------------- | --------------- |
| Blocks only ping | Blocks ALL ICMP |
| Networking works | May break apps  |

# 13. ICMP Rate Limiting (IMPORTANT)

## ✅ Secure Production Rule

```bash
sudo nft add rule inet filter input icmp type echo-request limit rate 5/second accept
```

Description:

* Prevents ping flood attacks

---

## Delete Rule

```bash
sudo nft delete rule inet filter input handle <ID>
```

---

# 14. ❌ Unsecure No-Limit Rule

```bash

```

Problem:

* Unlimited ping flood possible

# 22. ❌ VERY Unsecure IPv6 Rule

```bash
sudo nft add rule inet filter input ip6 nexthdr icmpv6 drop
```

Problem:

* Breaks IPv6 networking
* Breaks SLAAC
* Breaks neighbor discovery

---

# Difference

| Secure           | Unsecure    |
| ---------------- | ----------- |
| Blocks only ping | Breaks IPv6 |

# 23. Allow Essential ICMPv6 Only (BEST PRACTICE)

## ✅ Production-safe IPv6

```bash
sudo nft add rule inet filter input icmpv6 type {
    destination-unreachable,
    packet-too-big,
    time-exceeded,
    parameter-problem,
    nd-neighbor-solicit,
    nd-neighbor-advert,
    nd-router-advert,
    echo-request,
    echo-reply
} accept
```

Description:

* Allows only critical ICMPv6 traffic

---

## Delete Rule

```bash
sudo nft delete rule inet filter input handle <ID>
```

## IPv4

```bash

```

# 31. Security Comparison Summary

| Rule Type         | Secure | Unsecure |
| ----------------- | ------ | -------- |
| echo-request only | ✅      |          |
| echo-reply only   | ✅      |          |
| rate limiting     | ✅      |          |
| specific subnet   | ✅      |          |
| allow all ICMP    | ⚠      |          |
| block all ICMP    | ❌      |          |
| block all ICMPv6  | ❌❌     |          |

---

# 32. Best Practice Recommendations

✔ Allow essential ICMP
✔ Allow ICMPv6 neighbor discovery
✔ Use rate limits
✔ Allow only trusted ping if needed
✔ Use `ct state established,related`
✔ Never block all ICMPv6 blindly
